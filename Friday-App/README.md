# Friday — تطبيق صانع السيفي

## المحتويات
- `public/` : التطبيق (PWA قابل للتثبيت على الجوال)
- `server.js` : خادم صغير بدون مكتبات يقدّم التطبيق ويتصل بالذكاء الاصطناعي بأمان (المفتاح يبقى عند الخادم فقط)

## التشغيل على جهازك
```
ANTHROPIC_API_KEY=مفتاحك npm start
```
ثم افتح http://localhost:3000

## النشر للناس (مثال Render، مجاني للبداية)
1. ارفع هذا المجلد إلى مستودع GitHub خاص بك.
2. في Render: New → Web Service → اختر المستودع.
3. Start Command: `npm start`
4. Environment: أضف `ANTHROPIC_API_KEY` (مفتاحك من console.anthropic.com).
5. اختياري: `MAX_PER_DAY` (الافتراضي 500 طلب ذكاء اصطناعي يوميًا) و `MAX_PER_HOUR_PER_IP` (الافتراضي 15). هذا يحمي فاتورتك.
6. بعد النشر تحصل على رابط https، ويمكنك ربط دومين خاص.

## تثبيته كتطبيق
- **أندرويد (Chrome):** افتح الرابط ← القائمة ← تثبيت التطبيق.
- **آيفون (Safari):** مشاركة ← إضافة إلى الشاشة الرئيسية.
- **ملف APK لمتجر Google Play:** ادخل pwabuilder.com، ضع رابط موقعك، واختر Android.
- **App Store:** يحتاج حساب مطور Apple ويمر بمراجعة، ويمكن تغليف الموقع عبر PWABuilder أيضًا.

## ملاحظات أمان
- بدون `ANTHROPIC_API_KEY` يعمل التطبيق لكن بدون توليد نصوص بالذكاء الاصطناعي.
- لا تضع المفتاح داخل أي ملف في `public/`.
- حدّ الطلبات يعتمد على عنوان IP الذي ترسله منصة الاستضافة؛ استخدم منصة تضع هذا العنوان بنفسها (Render وRailway وFly).
